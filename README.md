# PORTFOLIO(LP・ホームページ制作実績)

LP・ホームページ制作の受注に向けた実績作りとして制作したサンプル集です。トップページ(入口)から「LP実績」と「ホームページ実績」の2つの一覧に分かれています。

いずれも架空のサービス・企業を題材にしたポートフォリオ用サンプルであり、実在の団体・人物とは関係ありません。

## 画面構成

- [トップ](./) — 入口。LP実績・ホームページ実績の2種類をカードで紹介
- [LP実績](./lp/) — 下記のLP 7本と改善事例の一覧
- [ホームページ実績](./website/) — 下記の複数ページサイトの一覧
- ヘッダーの「WORKS」はマウスを乗せる(スマホはタップ)と各実績のリストが開く(`assets/nav.js`)。フッターにも同じ一覧へのリンクがある

## メンテナンス

ページを追加・変更したら `python3 tools/ogp.py` を実行すると、全ページのOGP(URL共有時のプレビュー)タグと画像が更新されます(要Pillow)。実績一覧ページ(`lp/`・`website/`)に実績カード(Web版スクリーンショット)を載せた作品は、そのスクリーンショットがプレビュー画像になります(作品の下層ページも同じ画像)。
