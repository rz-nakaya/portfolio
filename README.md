# LP制作実績ポートフォリオ

LP制作の受注に向けた実績作りとして、代表的な7ジャンルで試作したランディングページ集です。

いずれも架空のサービス・企業を題材にしたポートフォリオ用サンプルであり、実在の団体・人物とは関係ありません。

## 制作者について

- [about](./about/) — 自己紹介・できること・ご依頼の流れ・お問い合わせ(フォーム/メール)

各フォルダの `index.html` をブラウザで開くと表示できます。

## メンテナンス

ページを追加・変更したら `python3 tools/ogp.py` を実行すると、全ページのOGP(URL共有時のプレビュー)タグと画像が更新されます(要Pillow)。トップページに実績カード(Web版スクリーンショット)を載せたLPは、そのスクリーンショットがプレビュー画像になります。
