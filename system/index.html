業務ツール実績

実際のご依頼で開発した、日々の手作業を減らすためのアプリです。どんな作業に困っていて、どう解決したかを中心に紹介しています。

※ 依頼元を特定できる情報(団体名・地域・使用機器など)は伏せています。画面の画像は説明用のサンプルデータで作成しています。

DESKTOP APP / EDUCATION実案件

通知表の一括印刷アプリ

学校からのご依頼。Excelで作った通知表を1人ずつ開いて印刷し、そのたびにプリンターの詳細設定を選び直していた作業を、「ファイルを選ぶ → 種類を選ぶ → 印刷する」の3ステップに。クラス全員分を冊子の形に面付けして、1回でまとめて印刷します。

  • Windows / macOS
  • PDF面付け
  • 自動テスト79件
  • 設計書一式
